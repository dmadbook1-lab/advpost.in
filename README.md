# ADVpost Landing Page

## Install & Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Placeholder assets
Drop your final images into `public/assets/` using these filenames referenced in the code:
- hero-chair.jpg, hero-sofa.jpg (Hero phones)
- why-phone.png (Why ADVpost section phone)
- storefront-1.png, storefront-2.png, storefront-3.png (Storefront section)
- product-hero.jpg, product.jpg (Product Showcase)
- posts-phone.png, post.jpg (Posts & Reels)
- cta-phone.png (Download CTA)

Everything is positioned to exactly the PDF layout — replacing these files will drop the real design in place with zero repositioning needed.
